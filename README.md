# BaiTu Project: End-to-End Enzyme Kinetics Prediction

This project implements a Physics-Informed Neural Network (PINN) for predicting enzyme kinetics parameters ($k_{cat}$, $K_m$) and reaction rates ($v_0$).

## Architecture

The model consists of three main modules:
1.  **Encoder Layer**: Extracts features from enzyme sequences (ESM), substrate SMILES (Morgan Fingerprints), and environmental conditions.
2.  **Parameter Predictor**: An MLP that predicts kinetic parameters ($k_{cat}$, $K_m$) from fused features.
3.  **Physics-Informed Layer**: A non-trainable layer that computes reaction rate $v_0$ using the Michaelis-Menten equation.

## Setup

1.  Install dependencies:
    ```bash
    pip install -r requirements.txt
    ```

2.  **Preprocess Data (Crucial Step):**
    Before training, you must generate the ESM-2 embeddings for your enzyme sequences. This script will download the ESM-2 model (default: 8M parameters), run inference, and save the embeddings to `data/kinetics_data_with_embeddings.pt`.
    ```bash
    python preprocess_esm.py
    ```

## Usage

To train the model:

```bash
python train.py
```

## Key Features & Risk Mitigation

-   **Scale Handling**: Predicts `log(k_cat)` and `log(K_m)` to handle order-of-magnitude differences.
-   **Modality Balance**: Uses LayerNorm and projection layers to balance high-dimensional enzyme embeddings and sparse molecular fingerprints.
-   **Numerical Stability**: Adds epsilon in the physics layer to prevent division by zero.
-   **Physics Constraints**: Enforces positive kinetic parameters via Softplus/Exp and strictly follows the Michaelis-Menten equation.
